# **App Name**: MozhiGenie

## Core Features:

- Real-time Transcription: Transcribes spoken Tamil from your microphone or from an uploaded audio file directly into Tamil text.
- AI Slang Normalization: Automatically converts colloquial or slang Tamil from the transcription into its standard, formal equivalent. Include a slang look-up tool.
- Multi-Language Translation: Translates the normalized Tamil text into a variety of languages, including English, Spanish, French, and more.
- AI-Powered Grammar Correction: Provides a tool to analyze and correct any grammatical errors in the normalized Tamil text with a single click. The AI model should prioritize accuracy and context to avoid unnecessary or incorrect corrections.
- Emotion Tone Detection: Analyzes the translated text to identify the emotional tone (e.g., happy, sad, angry, neutral) and displays a corresponding icon. The analysis should be highly accurate and nuanced to reflect the true emotional intent.
- Content Summarization: Generates concise summaries of the transcribed text in both Tamil and the selected translated language. The summaries should accurately capture the main points and context of the original text.
- PDF Report Generation: Allows you to download a comprehensive report in PDF format, containing the original transcription, normalized text, translation, emotion analysis, and summaries.  The PDF should have correct alignment and the text line by line aligned
- Text-to-Speech Playback: Reads the translated text aloud, converting it back into speech so you can hear the pronunciation.
- Three-Pane Interface: Implement a three-pane interface: original input, normalized Tamil, and translated text.
- Top Toolbar: Include a top toolbar with icons for key actions like recording, uploading, language selection, download, and settings.
- Voice Frequency Visualizer: Display a voice frequency visualizer while recording audio.

## Style Guidelines:

- Primary color: A deep forest green (#228B22) for a natural, calming feel.
- Secondary color: A dark charcoal black (#333333) for a professional, sophisticated look.
- Accent color: A bright lime green (#32CD32) for highlighting important UI elements and calls to action.
- Tamil font: 'PT Sans' (serif) for Tamil text for better readability. Note: currently only Google Fonts are supported.
- English and other languages font: 'Inter' (sans-serif). Note: currently only Google Fonts are supported.
- Design clear and intuitive icons for actions like recording, uploading, language selection, download, and settings. Use a consistent line style with lime green accents.
- Three-pane layout with original input, normalized Tamil, and translated text/analysis.
- Include a top toolbar with icons for key actions, and a loading animation with an AI processing bar to show status. The loading bar should include a percentage of completion.
- Incorporate subtle animations for loading states and AI processing to enhance the user experience. Use green-themed progress indicators.
