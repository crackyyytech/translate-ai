# Contributing

Thanks for improving this project.

## Workflow

1. Create a branch with a clear name, such as `feat/pdf-export` or `fix/translation-history`.
2. Keep changes focused and small enough to review.
3. Update docs when AI, export, deployment, or UI behavior changes.
4. Open a pull request using the template.
5. Include screenshots or short demos for UI changes.

## Quality Checklist

- The app installs cleanly.
- Type checks pass.
- No secrets, `.env` files, generated outputs, or private user content are committed.
- The PR explains the translation or user-facing impact.
